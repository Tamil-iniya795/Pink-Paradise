Pink Paradise – Online Shopping Website

About the Project
Pink Paradise is a simple and user-friendly online shopping website designed for women. It includes different shopping categories such as:

- 👗 Women's Fashion Wear
- 💎 Jewellery Collections
- 💄 Lipstick Collections
- 🎀 Hair Accessories

Technologies Used
- HTML
- CSS

How to Access the Project
1. Open the GitHub repository.
2. Click the Code button.
3. Select Download ZIP.
4. Extract the downloaded folder.
5. Open the `index.html` file in any web browser.

Output
The website displays a home page with different shopping categories. Users can click on each category to explore the available collections and products.

Project Objective
To create a simple and attractive online shopping website with an easy-to-use interface.
